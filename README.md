# 💬 Valora — Real-Time Chat Application

A modern real-time chat application built using the MERN stack with Socket.IO.

## 🚀 Live Demo

👉 [Visit Valora](https://valora-the-chat.onrender.com/)

## ✨ Features

- 🔐 User Authentication
- 💬 Real-Time Messaging
- 🟢 Online/Offline Status
- 🔍 User Search
- 🖼️ Image Sharing
- 😊 Emoji Support
- 📱 Responsive UI
